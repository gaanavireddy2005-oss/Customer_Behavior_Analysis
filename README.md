# Customer_Behavior_Analysis
# 🛍️ Customer Shopping Behavior Analysis

### End-to-End Data Analytics Project | Python • SQL • PostgreSQL • Power BI

## 📌 Project Overview

This project presents an end-to-end analysis of customer shopping behavior using a combination of **Python, PostgreSQL, SQL, and Power BI**.

The objective is to transform raw customer transaction data into meaningful business insights related to **customer demographics, purchasing patterns, sales performance, product categories, discounts, subscriptions, and customer segmentation**.

The project follows a practical data analytics workflow:

**Raw Data → Data Cleaning → Exploratory Data Analysis → SQL Analysis → Business Insights → Interactive Dashboard**

---

## 🎯 Business Objectives

The analysis focuses on answering key business questions such as:

* Which customer segments contribute most to overall sales?
* Which product categories generate the highest revenue?
* How do purchasing patterns vary across different customer demographics?
* What is the relationship between discounts and purchasing behavior?
* Which customers are subscribed to membership programs?
* How do different age groups and demographic segments behave?
* Which products or categories show opportunities for improving sales?
* What insights can help businesses improve customer engagement and retention?

## 🔄 Project Workflow

### 1. Data Collection

The customer shopping behavior dataset was imported and examined to understand its structure, columns, data types, and overall quality.

### 2. Data Cleaning & Preparation

The dataset was prepared for analysis by:

* Checking missing values
* Identifying duplicate records
* Validating data types
* Standardizing categorical information
* Preparing variables for analysis
* Creating analysis-ready data

### 3. Exploratory Data Analysis

Python was used to explore:

* Customer demographics
* Purchase frequency
* Product categories
* Purchase amounts
* Discounts
* Subscription behavior
* Customer purchasing patterns

Visualizations were created to identify trends, relationships, and potential business opportunities.

### 4. PostgreSQL & SQL Analysis

The cleaned dataset was loaded into **PostgreSQL** and analyzed using SQL.

SQL techniques used include:

* `SELECT`
* `WHERE`
* `GROUP BY`
* `ORDER BY`
* Aggregate functions
* `CASE WHEN`
* Filtering and segmentation
* Business-oriented analytical queries

The SQL analysis was designed to answer practical business questions rather than simply demonstrate SQL syntax.

### 5. Power BI Dashboard

An interactive Power BI dashboard was developed to communicate the major findings visually.

The dashboard provides a consolidated view of:

* Sales performance
* Customer demographics
* Product/category performance
* Purchasing behavior
* Customer segmentation
* Key performance indicators
